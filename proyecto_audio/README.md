# 🎙️ Sistema de Procesamiento y Análisis de Audios de Comentarios de Productos

Aplicación web desarrollada en Python, Streamlit, Whisper (IA local de transcripción) y SQLite para la gestión y análisis automatizado de notas de voz de clientes.

## ⚙️ Requisitos Previos e Instalación

1. Tener instalado **Python 3.8+** y **FFmpeg** en el sistema operativo.
2. Instalar las dependencias de Python:
   ```bash
   pip install -r requirements.txt
   ```

EJECUTAR:
python -m pip install openai-whisper
winget install Gyan.FFmpeg
streamlit run app.py
